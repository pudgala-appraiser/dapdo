# 답도 踏道

불교미술·미술사·문화유산 분야의 새 논문과 책을 두 달마다 정리하는 웹진입니다. 홀수 달(1·3·5·7·9·11월) 15일에 냅니다. 본문은 AI(Claude)가 공개된 서지와 초록을 바탕으로 엮습니다. 요지는 원문을 대신하지 않습니다.

- 공개 주소: https://pudgala-appraiser.github.io/dapdo/
- 운영자: 한재원

## 짜임

| 경로 | 내용 |
|---|---|
| `index.html` | 첫 화면. 지난 호 목록과 '이번 호' 링크는 `tools/build_issue.py`가 써 넣는다(`<!--issues:start-->` 표지 사이) |
| `issues.json` | 지난 호 목록(호 번호·이름표·건수). `tools/build_issue.py`가 고친다 |
| `issues/<id>.html` | 호마다 한 쪽. id는 발행한 달(YYYY-MM). `tools/build_issue.py`가 만든다. 손으로 고치지 않는다 |
| `data/issues/<id>.json` | 호 자료(정본). 앞선 호와 겹치는 문헌을 가리는 원장 구실도 한다 |
| `data/journals.json` | 국내 조사 대상 60종과 발간 달력. `mode`(전 논문 목록/관련 논문만), `cadence`(quarterly는 한 해 네 번, 1·5·7·11월 실행에서만 확인), `toc`(한국어 목차 쪽 주소 틀) |
| `data/intl.json` | 해외 조사 대상 후보 |
| `data/keywords.json` | 검색어 |
| `data/state.json` | 어느 날까지 확인했는지. `test`를 `true`로 두면 다음 실행이 시험 실행으로 돈다 |
| `tools/due.py` | 이번 호에 확인할 국내 학술지를 발간 달력으로 가린다 |
| `tools/portal_new.py` | 불교학논문 통합검색 저장소에서 새로 등록된 호의 논문을 뽑는다 |
| `tools/build_issue.py` | 호 자료를 검사하고 쪽을 만든다. 첫 화면의 지난 호 목록도 고친다 |
| `assets/dapdo.css` | 공통 양식. 글꼴은 Noto Serif KR·Noto Sans KR |
| `assets/namsan_cover.gif`·`.png` | 첫 화면 그림(경주 남산동 서삼층석탑 동면 야차·용). 한 번 재생되는 GIF와, 움직임을 줄인 환경에서 쓰는 정지 그림 |
| `assets/home.js` | 첫 화면 그림 크기 맞춤과 '다시 그리기' |
| `assets/mast.js` | 호 쪽 머리 그림(경주 장항리 서오층석탑 1층 탑신 북면 선화). 맨 위의 `K`·`KD`가 그리는 속도다 |
| `assets/pin.js` | 호 쪽에서 따라다니는 목차의 현재 위치 표시 |

## 호 자료 형식

```json
{
  "id": "2026-11",
  "title": "2026년 11월",
  "date": "2026-11-15",
  "updated": "발행한 뒤 같은 호에 문헌을 보탰을 때만: 보탠 날(YYYY-MM-DD)",
  "lead": "이번 호의 흐름을 두세 문장으로.",
  "model": "엮은 모델 표시명 (모델 ID)",
  "sections": [
    {
      "key": "art",
      "items": [
        {
          "authors": "저자",
          "title": "제목(원제 그대로)",
          "title_ko": "일본어·중국어·영어 제목의 한국어 번역(한국어 문헌이면 생략)",
          "venue": "『학술지』 권호 (연도) 또는 출판사, 연도",
          "url": "https://… (이번 실행에서 실제로 열었거나 검색 결과로 받은 주소)",
          "summary": "두세 문장 요지. 초록을 옮겨 적지 않고 다시 쓴다.",
          "flags": ["초록만 확인"],
          "deep": {"thesis": "핵심 논지", "material": "자료·사료", "method": "방법", "significance": "의의", "limits": "한계"}
        }
      ],
      "more": [{"authors": "저자", "title": "제목", "venue": "『학술지』 권호 (연도)", "url": "https://…"}]
    }
  ],
  "checked": [{"journal": "학술지", "issue": "확인한 호", "status": "확인 | 신규 없음 | 목차 미확인 | 이번 호 미확인"}]
}
```

- `key`는 `art`(불교미술·미술사), `heritage`(문화유산학·법제), `science`(AI·과학과 문화유산), `books`(신간) 가운데 하나.
- `deep`이 있는 항목은 ‘눈여겨볼 연구’에 실린다. 한 호에 3~5건.
- `flags`는 `초록만 확인`, `목차만 확인`, `서지 검증 필요`, `본문 미확인`, `원제 미확인`만 쓴다.
- 국내 학술지 논문은 한국어 원제와 한글 저자명으로 싣는다. 영문 목차만 본 채 번역한 제목을 원제처럼 쓰지 않는다. 한국어 원제를 끝내 찾지 못한 것만 영문 제목에 `원제 미확인`을 붙인다.
- `more`는 요지 없이 제목만 싣는 목록이다.
- 겹침: 앞선 호나 같은 호 안에 제목이 같거나 주소 속 식별 번호(DOI·arXiv·JAKO·KCI ART 등)가 같은 문헌이 있으면 `tools/build_issue.py`가 멈춘다. 목차 주소는 여러 논문이 함께 쓰므로 주소만으로는 가리지 않는다.
- 저자를 확인하지 못한 문헌은 학술지명(『 』)이나 식별 번호가 든 주소 가운데 하나는 있어야 싣는다.
- 발행한 호에 다시 실행해 문헌을 보탤 때: `date`·`no`·`label`과 이미 실린 문헌은 그대로 두고 `updated`에 보탠 날을 적는다. `model`이 다르면 가운뎃점으로 이어 함께 적는다. `checked`는 학술지마다 한 줄만 두고 최신 결과로 바꾼다.
- 최상위에 `"label"`을 두면 "제N호" 대신 그 이름으로 표시한다.
- 창간호: 2026년 11월호는 11월 10일에 시험 삼아 낸 "창간 준비호"(`"no": 0`)로 시작했다. 11월 15일 실행에서 준비호에 실린 문헌을 모두 안은 채 `"no": 1`, `"label": "창간호"`, `"date": "2026-11-15"`로 바꾸고 `updated`는 두지 않는다. 그다음 호(2027년 1월)가 제2호다.
